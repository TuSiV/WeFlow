# 使用指南：Windows 与 Mac 桌面版

适用于 `components/pinned-installer` 分支。已验证版本为 [5.0.1-preview.3](https://github.com/TuSiV/WeFlow/releases/tag/v5.0.1-preview.3)。后续版本以对应 Release 说明为准。

## 1. 安装与校验

| 系统 | 下载文件 | 支持范围 |
| --- | --- | --- |
| Windows | `Windows-x64-Setup.exe` | Windows 10+、x64 |
| Mac | `macOS-arm64.dmg` 或 `macOS-arm64.zip` | macOS 15+、M 系列芯片；不支持 Intel |

三个安装文件和 `SHA256SUMS.txt` 放在同一个 Release。Windows 运行安装程序；Mac 打开 DMG，将 WeFlow 拖到“应用程序”，或解压 ZIP 后安装应用。Mac 当前使用 ad-hoc 签名，未经过 Apple 公证。系统阻止打开时先对照下载来源和校验值，见 [故障排查](TROUBLESHOOTING.md)。

可在 Windows PowerShell 用 `Get-FileHash -Algorithm SHA256 '安装文件路径'`，在 Mac 终端用 `shasum -a 256 '安装文件路径'`，将结果与同一版本的 `SHA256SUMS.txt` 比较。

## 2. 选择本机账号

1. 在配置引导的数据库目录／密钥步骤扫描账号。也可浏览微信设置显示的存储位置，或直接选择账号目录。
2. 从列表选择需要读取的账号，应用回填数据根目录和账号 ID；完整目录名及后缀保留，不要改成昵称或自行猜微信号。
3. 切换账号会清除旧密钥。目录扫描结果只证明存在本地数据，不表示该账号当前已登录。

Mac 默认扫描的常见位置包含 `~/Library/Containers/com.tencent.xinWeChat/Data/Documents/xwechat_files`；自定义位置需手动浏览。仅支持新版 `db_storage/session` 布局，旧版 `Msg/MicroMsg.db` 会标为暂不支持。

## 3. 获取和验证密钥

正常使用安装包时，第三方组件路径保持留空，使用已校验的随包组件。显式设置外部路径会优先使用外部实现，见 [组件接口](third-party-components.md)。

- 数据库：选择账号后点击“自动获取密钥”。Windows 使用随包适配器；Mac 使用随包辅助程序，要求只运行一个微信主实例。返回的候选密钥必须能打开所选账号，才能保存／回填。
- Mac 权限拒绝：可取消，或通过系统授权窗口重试一次。应用不修改 SIP、微信签名及系统调试设置；管理员授权不保证目标微信版本允许访问。
- 手动方式：填写该账号的 64 位十六进制数据库密钥，再完成连接验证。不要使用其他账号的密钥。
- 图片：获取图片密钥前，在当前账号中打开几张图片大图。Mac 优先读取缓存代码、推导候选并用本账号图片模板验证；没有模板或账号不匹配不会作为成功结果。

真实微信进程中的取钥成功尚未被本项目 CI 验证。内置工具能启动、接口流程能通过测试，不等于对所有微信版本兼容。

## 4. 导出完整聊天 PDF

打开目标会话的导出配置，选择 PDF、输出目录及需要的时间／媒体选项，开始导出。PDF 使用完整静态消息生成 A4 分页文档，不依赖聊天窗口或 HTML 的虚拟滚动；包括标题、消息时间、正文、图片及页码。使用随包 Noto 中文字体。

PDF 不播放音视频；语音／视频以文字标识、可用视频封面及现有媒体另存设置呈现。选择导出附件不等于所有附件都已经存在于本机。具体失败应查看导出结果，见 [故障排查](TROUBLESHOOTING.md)。

## 5. 只导出指定消息

1. 在聊天消息上右键进入“多选”，勾选需要的消息。
2. 点击底部“导出选定消息”。配置默认 PDF，也可切换其他现有格式。
3. 确认选择条数及输出目录后导出。此模式忽略全局时间范围，只按所选消息的完整标识读取；文件名带“选定 N 条”，同名文件保留副本。

所选消息已删除、读取失败或标识存在歧义时，导出失败，不会静默扩大为整个会话。刷新聊天后重新选择。成功导出后核对起止消息、发送人、时间、条数和附件；测试数据的跨页完整性不替代真实账号的核对。

## 6. 数据与操作范围

本轮验证覆盖读取、解密及导出，并不是对原有消息修改／删除、防撤回、朋友圈或全部分析功能的完整验收。处理需要保留的记录时，先保留数据库和附件副本，避免使用本地消息修改／删除功能改变来源数据。

聊天读取和导出使用本机组件；手动启用外部 AI 服务或其他联网功能时，数据流取决于该功能配置，不能把项目描述中的“本地”理解为所有可选功能都不联网。不要公开密钥或含聊天正文的调试资料。
