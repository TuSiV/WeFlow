# 故障排查

适用于本分支随包 Windows x64 / Mac arm64 版本。先记录应用版本、系统版本、芯片／架构、微信版本、所选数据目录和完整错误码；不要附上密钥、聊天正文或原始数据库。

| 现象 | 排查与处理 |
| --- | --- |
| 扫描不到账号 | 浏览微信设置显示的存储位置，检查账号目录是否有非空 `db_storage/session/session.db`；Mac 确认应用能访问相应数据目录。目录存在不代表兼容。 |
| 旧版 `Msg/MicroMsg.db` 被禁用 | 本版只支持新版数据布局，手动修改账号 ID 不会使旧布局可连接。 |
| 自动获取结果无法打开所选账号 | 重新确认列表选择与当前微信账号一致；切换账号后重新获取，不复用旧密钥。Mac 候选密钥验证失败不会返回成功。 |
| Mac 提示系统拒绝访问微信 | 可取消或选择系统管理员授权重试一次；若仍被拒绝，改用手动密钥或明确兼容的外部工具。不要通过关闭 SIP、修改微信签名反复尝试。 |
| Mac 检测到多个实例／未找到进程 | 保留需要读取的一个微信主实例，先打开微信，再获取；应用不会替用户广泛终止进程。 |
| 取消系统管理员授权 | 本次获取失败／取消，不保存候选密钥；无需输入或保存密码到 WeFlow。 |
| 当前微信特征未匹配／等待超时 | 保持微信打开并切换会话后重试；持续失败表示当前路线未兼容或访问受限，不表示账号没有聊天。 |
| 图片缓存代码或模板缺失 | 在所选账号打开几张图片大图；确认本账号图片缓存可读。没有有效模板不能确认图片密钥归属。 |
| 图片密钥与账号对不上 | 重新选择准确账号目录，不用其他账号模板；不把未校验候选手动当成成功结果。 |
| 原生库／辅助程序缺失或校验失败 | 下载同一 Release 的完整安装包并校验 SHA-256，重新安装；源码环境重新执行对应平台 `components:install`。不要混用不同版本原生文件。 |
| PDF 提示中文字体缺失／加载失败 | 安装包应包含 Noto 字体；源码环境保留 `resources/fonts/annual-report/NotoSerifSC-Var.ttf`，不要只复制 EXE 或主程序代码。 |
| PDF 生成超时 | 缩小导出范围后重试，查看媒体文件读取情况；不要把残留临时文件当成完整导出。 |
| 所选消息已变化或无法读取 | 刷新会话并重新勾选；缺失／歧义消息必须失败，不能改为导出整段来替代选择结果。 |
| 数据库到期或 `wcdb_init` 失败 | 对照当前安装包版本、具体错误码和组件校验；本分支只转换已知固定来源的日期检查，不能套用于任意库。不要据泛化提示直接关闭安全防护。 |

## Mac 首次打开被阻止

当前版本使用 ad-hoc 签名，未使用 Apple Developer ID 签名和公证。先核对 Release 来源、macOS 15+／M 系列要求及文件校验值，再查看系统提示。校验不符或出现无法确认来源的文件时，重新下载完整包，不批量移除隔离标记或修改系统保护设置。

## PDF 文本核对

某些 CJK 字体可能将同形字映射为 Unicode 兼容字符，例如“文”与其康熙部首。当前自动测试对提取文本做 NFKC 兼容规范化核对；不意味着所有阅读器中的逐字复制、精确字符串搜索都一致。若用于精确文本处理，核对原消息及复制结果，不仅检查页数。

## 哪些问题仍未验证

CI 没有真实微信账号。真实进程取钥成功、多年聊天及附件完整性、所有微信版本的兼容性均未证实。查看 [测试说明](TESTING.md) 区分实际原生运行、模拟候选密钥及真实账号测试。

设置页个别旧提示仍只提到 Windows 随包组件；Mac 的实际支持以当前 [组件状态](native-components-status.md)、引导页及此说明为准，该旧文案不表示 Mac 需要自备全部组件。
