# 双平台预发布说明

当前已验证版本为 [5.0.1-preview.3](https://github.com/TuSiV/WeFlow/releases/tag/v5.0.1-preview.3)。安装与导出步骤见 [使用指南](USER-GUIDE.md)，测试范围与复现命令见 [测试说明](TESTING.md)，常见错误见 [故障排查](TROUBLESHOOTING.md)。后续版本以对应 Release 和运行记录为准。

Windows 与 Mac 统一预发布版本：同一提交、同一版本号，两个平台各自测试和打包全部通过后才发布。请选择对应系统的安装包：

- Windows x64：Windows-x64-Setup.exe。
- Mac Apple Silicon（M 系列、macOS 15+）：macOS-arm64.dmg 或 macOS-arm64.zip；不支持 Intel Mac。
- SHA256SUMS.txt：以上三个文件的 SHA-256 校验值。

支持直接将完整聊天记录导出为 A4 PDF，也支持勾选指定消息单独导出。PDF 包含标题、时间、正文和页码，使用随包 Noto 中文字体；所选消息缺失或存在歧义时导出失败，避免误导出整个会话。

包含固定来源并校验的数据库库和图片解密插件，修复固定日期到期导致的数据库初始化失败；不改变系统时间，保持数据库密钥与宿主校验。支持本机账号目录扫描和选择。默认使用源码消息游标导出，未分发 WeLive 通信引擎。

Windows 包含密钥适配器。Mac 新增内置数据库密钥获取工具，自动寻找唯一微信进程、尝试获取密钥并验证所选账号；系统拒绝访问时可通过系统授权重试一次。图片密钥优先从本账号缓存推导，并用图片模板校验；缺少模板或账号不匹配不会返回成功。进程访问限制或未适配的微信版本仍可能导致失败，此时可手动填写或配置外部工具。不会关闭 SIP 或修改微信签名。仅支持新版 db_storage/session 数据布局。

两个平台发布前均验证实际 Electron 原生初始化、模拟加密数据库会话和消息读取、图片解密、HTML 导出、620 条消息跨页 PDF 完整性、仅选首尾两条 PDF、实际加密数据库 PDF、缺失消息失败清理及 React 账号/导出界面。Mac 安装包另验证随包原生文件、字体和代码一致性，并重新运行包内资源测试与签名检查。CI 使用模拟数据，未使用真实微信账号。

Mac 使用 ad-hoc 签名，未使用 Apple Developer ID 签名和公证。

新增测试：辅助程序结果格式与权限错误、图片缓存推导和账号隔离、无模板拒绝；Mac 实机 CI 验证原生密钥库符号及两个辅助程序对无效 PID 的拒绝。未在真实微信进程中验证取钥成功，不承诺所有微信版本均兼容。
