# 历史 Windows 单平台发布说明

本文件保留双平台统一发布前的 Windows 功能与验证记录，不作为当前完整平台支持说明。当前版本见 [统一发布说明](desktop-release-notes.md) 和 [组件状态](native-components-status.md)；未改写已公开历史 Release。

新增直接 PDF 导出：导出配置中选择 PDF 即可生成 A4 分页文档，含聊天标题、消息时间、正文、图片和页码。使用完整静态内容生成，不依赖 HTML 的虚拟滚动；语音与视频以文字标识及可用视频封面呈现，附件按现有媒体设置另存。

新增勾选消息导出：聊天消息右键进入“多选”，勾选后点击底部“导出选定消息”；默认 PDF，也可选择现有导出格式。只包含所选消息，忽略全局时间范围；文件名带“选定 N 条”，同名文件保留副本。消息已删除、读取失败或标识存在歧义时导出失败，不扩大为整个会话。

新增本机微信账号扫描与选择：引导页自动扫描常见数据目录；可扫描所选自定义目录，支持直接选择账号目录。列表显示真实目录标识及路径，点击后填入数据库根目录和账号 ID。切换账号清除旧密钥，自动获取后先验证能打开所选账号的数据库，保留手动输入。旧版 Msg/MicroMsg.db 数据会标明暂不支持，不会当作新版可连接账号；目录列表不表示当前登录状态。

Windows x64 桌面安装包，包含固定来源并校验的数据库库、媒体解密插件和密钥适配器。

修复数据库包装库内部的固定日期到期检查；不修改系统时间。仅转换已知原始 SHA-256 的 DLL，校验完整输出及同目录依赖；保持两个跳转目标和指令长度。修复来源及许可证随包保存。

默认使用应用现有源码中的消息游标和格式化导出流程。已报告到期错误的 WeLive 及其通信 DLL 不随包加载或分发；自备外部引擎仍可通过显式路径选择。原生游标读取或批次失败会使导出失败，避免将中断记录输出为成功文件。

发布前 Windows 检查：实际 Electron 主进程初始化；应用 WcdbCore 适配器读取模拟加密会话和消息；模拟图片解密；实际 exportWorker 通过源码流程成功导出模拟聊天 HTML；实际 React 页面选择回填、切换密钥清空、错误密钥拒绝及空结果提示；多账号、带后缀账号的精确目录解析、嵌套与自定义路径、旧版/空目录过滤测试；类型检查、生产构建及 NSIS 打包；620 条模拟消息的 PDF 逐条文本提取及跨页完整性检查、仅选首尾两条的 PDF 排除中间消息、实际加密 WCDB 的 worker 到主进程 PDF 导出、缺失消息失败及临时文件清理、实际 React 导出配置的 PDF 与 HTML 切换检查。SHA256SUMS.txt 对应此安装包。

这是预发布版本。CI 没有真实微信账号，因此尚未验证从微信进程获取密钥、真实多年聊天及附件的完整导出。导出供打印时，先在数据库副本上核对消息数量、发送人、时间和附件。不要仅凭导出成功判断记录完整。
