Windows x64 桌面安装包，包含固定来源并校验的数据库库、媒体解密插件、密钥适配器和导出引擎。

修复数据库包装库及导出引擎内部的固定日期到期检查；不修改系统时间。仅转换已知原始 SHA-256 的 DLL 和 EXE，校验完整输出及同目录依赖；保持 DLL 两个跳转目标及所有转换位置的指令长度；导出引擎只移除进入到期退出路径的六字节分支。修复来源及许可证随包保存。

发布前 Windows 检查：实际 Electron 主进程初始化；应用 WcdbCore 适配器读取模拟加密会话和消息；模拟图片解密；WeLive 成功导出模拟聊天 JSONL；类型检查、生产构建及 NSIS 打包。SHA256SUMS.txt 对应此安装包。

这是预发布版本。CI 没有真实微信账号，因此尚未验证从微信进程获取密钥、真实多年聊天及附件的完整导出。导出供打印时，先在数据库副本上核对消息数量、发送人、时间和附件。不要仅凭导出成功判断记录完整。
