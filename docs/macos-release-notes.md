# Mac 平台发布说明

Mac 与 Windows 安装包位于 [同一个预发布 Release](https://github.com/TuSiV/WeFlow/releases/tag/v5.0.1-preview.3)，本文件仅说明 Mac 平台差异。完整操作见 [使用指南](USER-GUIDE.md)，实际验证范围见 [测试说明](TESTING.md)，权限与启动问题见 [故障排查](TROUBLESHOOTING.md)。

Mac 桌面预发布版本，适用于 macOS 15 及以上、Apple Silicon（M 系列芯片、arm64）。提供 DMG 安装包和 ZIP 应用包，不支持 Intel Mac。

包含固定来源并校验的 WCDB 数据库库和图片解密插件，默认使用应用源码消息游标导出，不需要用户另行配置数据库库路径。包含直接 A4 PDF 导出和勾选指定消息导出。PDF 使用随包 Noto 中文字体，支持正文文本提取；字体许可证随包提供。

密钥配置：Mac 版已内置数据库及图片密钥辅助程序；数据库候选密钥必须验证所选账号，图片优先从缓存推导并验证。部分微信版本拒绝进程访问或特征未适配时仍需手动填写或配置外部工具。可选择系统管理员授权重试，不修改 SIP、微信签名或系统调试设置。真实微信取钥成功尚未在 CI 验证。Windows 的 wx_key.dll 不适用于 Mac。支持新版 db_storage/session 数据布局，旧版 Mac 微信数据库布局不在本版本支持范围。

修复固定数据库库的日期到期初始化失败，保持原有宿主校验和数据库密钥校验；只接受已知原始文件，转换后校验完整文件与 ad-hoc 签名，修改说明随包提供。未改变系统时间。

引导页扫描 Mac 微信常见容器中的 xwechat_files 目录；也可浏览微信设置显示的存储位置或直接选择账号目录。

发布流程要求 macOS arm64 实际 Electron 原生初始化、错误数据库密钥拒绝、正确密钥下模拟加密数据库读取、图片解密、源码 HTML 导出、620 条消息跨页 PDF 完整性、指定两条 PDF 排除其他消息、实际加密数据库 PDF 导出及缺失消息失败清理、React 账号选择和导出配置测试全部通过。打包后核验内置原生文件和发布代码，并重新执行针对 .app 内原生资源的导出测试。CI 不使用真实微信账号。

此版本未使用 Apple Developer ID 签名和公证，采用本地 ad-hoc 签名。SHA256SUMS.txt 用于校验下载文件。
